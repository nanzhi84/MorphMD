# ADR-0002: 版本化同构交付快照、多比例分页引擎与静态资产自由复制管线

- **状态 (Status)**：Accepted
- **日期 (Date)**：2026-10-23
- **取代决策 (Supersedes)**：[0001-unified-ast-and-pluggable-view-adapters.md](superseded/0001-unified-ast-and-pluggable-view-adapters.md)

## 1. 背景与上下文 (Context)

在 [ADR-0001](superseded/0001-unified-ast-and-pluggable-view-adapters.md) 确立“单一 Unified AST + 可插拔视图适配器 + 双层样式体系”的基础上，进一步面向**高性能实时所见即所得（WYSIWYG）**、**多平台渲染拓展**、**自定义 CSS 跨视图兼容**以及**类 Typora 图片粘贴与右栏自由复制**进行架构核验时，原方案暴露出四项关键缺口：

1. **后置处理导致“伪所见即所得”**：原方案将列表降级、样式内联与公式/SVG 光栅化放在点击“复制/导出”阶段执行，导致预览态 DOM 与实际交付产物存在结构与视觉偏差，且无法支持用户在右侧预览区直接用鼠标框选局部图文按 `Cmd/Ctrl + C` 自由复制。
2. **`cards` 画布比例僵化与增量分页盲区**：原方案将 `cards` 写死为单一尺寸（且误将 $1:\sqrt{2}$ 的 `1440×2036` 标注为 `3:4`），无法满足创作者在 `3:4`、`4:5`、`1:1`、`16:9` 等常用社交画布比例间自由切换的需求；同时未定义内容缩短时的向上回填（Look-back Reflow）及超高原子块的防死循环兜底策略。
3. **CSS 内联与跨平台能力边界模糊**：单纯依赖 `getComputedStyle` 全量拷贝会混入数百项浏览器默认属性，而单纯依赖 CSS AST（如 `css-tree`）又无法独立完成浏览器级层叠、继承与相对单位计算；此外对 `x-article` 等会剥离行内样式的强托管平台缺乏显式的样式能力守卫。
4. **缺少静态资产管线（`AssetStore`）与选区重建机制**：直接将粘贴图片转为 Base64 插入左栏源码会导致编辑器严重卡顿；而右栏若仅使用 `Range.cloneContents()` 响应原生框选复制，会丢失块级祖先标签（如仅选中标题内几个字时丢失 `<h2>` 及颜色）并在跨站粘贴时因 `blob:` 协议失效而裂图。

## 2. 决策方案 (Decision)

### 2.1 统一语义 AST、重型块缓存与版本化交付快照（Versioned Delivery Snapshot）
1. **全量轻量解析 + 重型节点分层缓存**：
   - 原始 Markdown 文本与资产清单作为唯一可持久化文档源；每次文本变更执行全量轻量级 `mdast` 解析（确保跨块引用定义 `[ref]: url` 与代码围栏边界完全准确），各视图基于统一 AST 派生各自不可变的输出树。
   - 仅对耗时显著的重型节点（Shiki 代码高亮、KaTeX 数学公式、SVG/降级块派生图片）按 `内容 Hash + 语言/主题/目标能力版本` 进行细粒度 Memoization 缓存；严格区分“内容 Hash（能否复用）”、“稳定节点 ID（区分同文段落）”与“源码范围映射（`data-source-range`，支撑双栏精准滚动同步）”。
2. **前置转换与版本化交付快照**：
   - 将目标平台结构降级、受控样式内联与派生图像资源准备**前置到预览生成阶段**，生成不可变的 **版本化交付快照（Versioned Delivery Snapshot）**（包含源文档版本、样式版本、资源就绪状态、源码映射与降级诊断）。
   - 右栏可交互预览 DOM、顶部「一键复制全文」、右栏鼠标局部框选复制（`Cmd/Ctrl + C`）及 PNG/ZIP 导出统一消费同一份已就绪交付快照，杜绝导出器临时拼装未预览状态。

### 2.2 可组合视图算子与多比例确定性分页引擎
1. **保持轻量适配器 + 正交公共算子组合**：
   - 首版聚焦 `wechat`、`x-article`、`cards` 三个视图适配器，不预设僵化的多层基类继承树，而是将通用能力沉淀为正交可组合算子：`resolveAssets`（资产解析）、`inlineAllowedStyles`（受控样式内联）、`normalizeSelection`（选区上下文规范化）与 `paginateDom`（流式分页）。
   - 每个适配器通过 `capabilities` 明确声明支持的语义节点、CSS 属性子集以及图片交付模式（`imageTransport`：HTML 内嵌 `data:` / 指定 `https:` 图床外链 / 平台上传接口）。
2. **`cards` 可选常用画布比例预设**：
   - `cards` 视图内置常用社交媒介画布比例预设，支持创作者实时切换并响应式重排：
     - **`3:4` 竖版图文卡片**：导出基准分辨率 `1440×1920`（CSS 布局尺寸 `360×480` 或 `720×960`）
     - **`4:5` 社交贴图卡片**：导出基准分辨率 `1440×1800`
     - **`1:1` 方形图文卡片**：导出基准分辨率 `1440×1440`
     - **`16:9` 横版演示卡片**：导出基准分辨率 `1920×1080`
   - 严格分离 **CSS 布局像素**、**预览缩放倍率（`transform: scale()`）** 与 **导出光栅化倍率**，防止宿主 `devicePixelRatio` 造成二次叠加缩放。
3. **回溯增量分页（Look-back Reflow）与超高原子块兜底**：
   - 分页失效由内容、样式、字体加载与资产尺寸就绪显式驱动（`ResizeObserver` 仅作辅助观测）；局部变更时从最早受影响页的**前一页检查点 `max(1, K - 1)`** 开始重算，确保第 $K$ 页内容缩短时能正确向上回填至第 $K-1$ 页，直到分页边界与既有页面重新收敛。
   - **超高原子块策略**：当单张图片、公式块或单行表格高度超过单页可用内容区高度时，自动应用 `max-height: 100%; object-fit: contain` 等比缩放或强制拆分并给出诊断提示，严禁产生无限换页死循环或空白废页。

### 2.3 Design Tokens、语义类名契约与受控白名单样式内联
1. **共享 Design Tokens 与稳定语义类名契约**：
   - 顶层提取跨视图 CSS 变量（`--morph-bg`、`--morph-ink`、`--morph-accent`、`--morph-font-serif`、`--morph-font-sans`、`--morph-font-mono`、`--morph-body-size`、`--morph-line-height`、`--morph-block-gap`），并为输出节点赋予稳定的 `.morph-h1`..`h3`、`.morph-p`、`.morph-quote`、`.morph-callout`、`.morph-code`、`.morph-card-page` 语义类。
2. **CSS AST 属性白名单 + 浏览器受控 `getComputedStyle` 提取**：
   - 使用 `css-tree` 解析预设主题与用户 Custom CSS，校验选择器安全性并提取实际声明过的 CSS 属性白名单；
   - 由浏览器原生布局引擎完成层叠优先级、继承、相邻/父子选择器及 `var(--morph-*)` 求值后，仅按该白名单及目标平台允许的属性子集从 `getComputedStyle(el)` 中提取计算值写入行内 `style`；对明确支持的简单装饰性 `::before` / `::after` 规则实体化为 `<span data-morph-pseudo>` 节点。
3. **平台样式能力守卫（Style Capability Guard）与安全隔离**：
   - 对 `x-article` 等会清洗行内 `style` 的强托管平台，正文预览锁定为仿真平台原生排版，Design Tokens 与自定义 CSS 仅作用于自动降级为图片的内嵌节点（如复杂表格、代码块、数学公式），并在界面输出可定位的降级诊断。
   - 严格校验原始 HTML、SVG 与 URL 协议，限制 `[data-view]` 样式作用域及危险布局属性（如分页视图中会导致吞字的未授权 `overflow: hidden` 或脱流定位），防止污染宿主界面。

### 2.4 `AssetStore` 静态资产管线与右栏图文一体自由复制
1. **左栏 `morph-asset://` 短协议与显式异步状态机**：
   - 拦截左栏编辑器 `paste` / `drop` 事件中的图片二进制数据（妥善处理图文混合粘贴与撤销竞态），左栏源码仅插入短引用 `![alt](morph-asset://<id>)`；支持导出携带相对路径 `./assets/` 的标准文档包。
   - `AssetStore` 维护有界内存缓存与显式状态机：`已接收 -> 元数据就绪（完成 EXIF 方向与天然宽高归一化） -> 预览就绪（blobUrl） -> 交付表示就绪（与预览视觉一致的 dataUrl 或已验证图床 https URL）`，按引用计数与导出锁释放 `Blob URL`。
2. **右栏图文一体自由复制与选区上下文重建（Selection Context Normalizer）**：
   - 不设单图单独复制步骤，统一支持**顶部「一键复制全文」**（基于 Async Clipboard API 读取完整交付快照）与**右栏鼠标自由框选 `Cmd/Ctrl + C` 复制**（拦截原生 `copy` 事件）。
   - **选区上下文重建**：当用户在右栏进行局部框选（如仅选中标题内几个字、嵌套强调、有序列表中段或跨卡片框选）时，`Selection Context Normalizer` 基于 `Range` 自动向上回溯并包裹必要的块级/行内祖先标签与计算样式（如补回 `<h2>`、补齐 `<ol start="N">`），自动剔除 `cards` 视图生成的页眉、页脚与跨页重复表头，并将选区内的图片、公式等原子节点同步替换为已就绪的交付表示，同时写入 `text/html` 与保留替代文本的 `text/plain`。

## 3. 影响与后果 (Consequences)

- **正面收益**：
  - **真所见即所得与多比例灵活制卡**：预览、全文复制、局部框选复制与多比例卡片导出严格共享同一份交付快照；创作者可在 `3:4`、`4:5`、`1:1`、`16:9` 等常用比例间无缝切换。
  - **左栏零卡顿、右栏自由复制**：左栏保持清爽短链接，右栏即使局部框选半句话加一张图也能完整保留外层标题/列表样式与内嵌图片数据。
  - **样式计算精准可控**：结合了 CSS AST 的静态白名单安全边界与浏览器原生层叠计算的准确性。
- **潜在代价与工程约束**：
  - 需实现专门的 `Selection Context Normalizer` 处理跨块/跨页 DOM 选区重建及重复表头剥离。
  - 各目标平台的图片粘贴持久化能力受外部编辑器策略制约，必须针对目标平台实测验证“粘贴后保存并刷新仍存活”的闭环。
